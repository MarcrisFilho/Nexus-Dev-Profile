## Rodando localmente

Requer **Node.js 22 ou superior** e npm. Substitua `URL_DO_REPOSITORIO` pela URL deste projeto no GitHub.

```bash
git clone URL_DO_REPOSITORIO Nexus-Dev
cd Nexus-Dev
npm install
npm run dev
```

Abra o endereço exibido no terminal. Se você já tem a pasta do projeto, execute apenas `npm install` e `npm run dev` dentro dela.

Para gerar e conferir a versão de produção:

```bash
npm run build
npm run preview
```

Na Vercel, use o preset **Vite**, o comando `npm run build` e o diretório de saída `dist`.
